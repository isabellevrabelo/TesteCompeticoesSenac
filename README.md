# TesteCompetições Senac

## 📌 Sobre o projeto

O **TesteCompetições Senac** é um projeto desenvolvido para praticar e aprimorar conhecimentos em desenvolvimento web, utilizando tecnologias estudadas durante a formação técnica em Tecnologia da Informação.

O projeto tem como objetivo aplicar conceitos de programação, organização de código, desenvolvimento de interfaces e integração com banco de dados.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- Bootstrap
- Git e GitHub

## ⚙️ Funcionalidades

- Sistema de autenticação de usuários.
- Gerenciamento de informações.
- Integração com banco de dados.
- Separação de funcionalidades por páginas e arquivos PHP.

*As funcionalidades podem variar conforme a implementação atual do projeto.*

## 💻 Como executar o projeto

### Pré-requisitos

- [XAMPP](https://www.apachefriends.org/pt_br/index.html) instalado.
- Git instalado.
- Navegador web.

### Instalação

1. Clone o repositório:

   ```bash
   git clone https://github.com/isabellevrabelo/TesteCompeticoesSenac.git
   ```

2. Coloque a pasta do projeto no diretório `htdocs` do XAMPP.

3. Inicie o Apache e o MySQL pelo painel do XAMPP.

4. Configure o banco de dados conforme os arquivos SQL do projeto, se houver.

5. Configure a conexão com o banco de dados de acordo com o ambiente local.

6. Acesse o projeto pelo navegador:

   ```text
   http://localhost/TesteCompeticoesSenac/
   ```
